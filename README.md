# بوابة أبحاث التخرج - كلية الدعوة الإسلامية

الهيكل: `public/` (الواجهة) · `functions/` (الخادم والصلاحيات) · `schema.sql` (الجداول) · `wrangler.toml`.
مهم: مجلد الإخراج في Cloudflare Pages = `public` حتى لا تُعرض ملفات الخادم للعموم.

## مصفوفة الصلاحيات (تُعدَّل في functions/_lib.js)
| الإجراء | طالب | المشرف | إدارة الكلية |
|---|---|---|---|
| رفع بحث | لنفسه | لأي طالب | لأي طالب |
| رفع نسخة ملف | بحثه فقط، وفي حالة جديد أو يحتاج تعديل | أي بحث | أي بحث |
| عرض الأبحاث | بحثه فقط | الكل | الكل |
| تعديل العنوان والملخص | بحثه فقط (جديد/يحتاج تعديل) | نعم | نعم |
| تغيير الحالة والتقييم | لا | نعم | نعم |
| تنزيل الملفات | لا | لا | نعم (ويُسجَّل) |
| إنشاء حسابات الطلاب وإعادة كلمات المرور | لا | نعم | نعم |
| إنشاء حسابات الموظفين والإدارة | لا | لا | نعم |

## ضمانات الأمان
- التحقق من الصلاحية في الخادم لكل طلب، وليس بإخفاء الأزرار.
- الطالب لا يرى بحث غيره (يظهر "غير موجود").
- ملفات KV خاصة بلا رابط عام، والتنزيل عبر الخادم فقط.
- كلمات المرور مشفّرة PBKDF2، والجلسة كوكي HttpOnly لمدة 8 ساعات.
- قفل 15 دقيقة بعد 5 محاولات دخول فاشلة، وكلمة مرور مؤقتة تُغيَّر عند أول دخول.
- الرفع: PDF/Word حتى 20 ميغابايت مع فحص محتوى الملف، والنسخ القديمة تُحفظ.
- سجل تدقيق (audit) لعمليات الرفع والتنزيل وإدارة الحسابات.

## خطوات الإعداد (مرة واحدة)
1. `npx wrangler d1 create research-db` ثم ضع `database_id` في wrangler.toml.
2. `npx wrangler d1 execute research-db --remote --file=schema.sql`
3. `npx wrangler kv namespace create FILES` (أو من اللوحة: Storage & databases ← KV ← Create، واسمه research-files)
4. في Cloudflare Pages للمشروع: Settings ← Bindings: أضف D1 باسم `DB` وKV namespace باسم `FILES` (إن لم يُقرأ wrangler.toml).
5. أضف متغيراً سرياً `SETUP_TOKEN` بقيمة طويلة عشوائية.
6. أنشئ أول حساب إدارة مرة واحدة: أرسل POST إلى `/api/setup` بالجسم
   `{"token":"...","username":"admin","name":"...","password":"كلمة-مرور-طويلة"}`
   ثم احذف المتغير `SETUP_TOKEN`.

## تحديث للقاعدة الموجودة (تصنيفات وأماكن الدراسة والمشرفين)
شغّل محتوى `migration.sql` مرة واحدة في D1 Console. للتثبيت الجديد يكفي `schema.sql`.
- تصنيف الطلاب: طلاب / طالبات. مكان الدراسة: دير البلح / الشمال. يُحددان عند إنشاء حساب الطالب ويُنسخان لأبحاثه.
- تصنيف البحث: قرآن كريم، حديث شريف، فقه، عقيدة، دعوة، تربية، تاريخ، لغة عربية، لغة إنجليزية.
- المشرفون الأكاديميون: قائمة تديرها الإدارة فقط (تبويب «المشرفون»)، ويختار الطالب منها.

## التحديث الثاني: الاستعلام والروابط البحثية والمكتبة
شغّل `migration-2.sql` مرة واحدة في D1 Console (جدولا links وlibrary). للتثبيت الجديد يكفي `schema.sql`.
- **استعلام** (للمشرف والإدارة): فلاتر السنة والتصنيف ومكان الدراسة والحالة والمشرف الأكاديمي والاسم، مع تصدير النتائج إلى ملف CSV يفتح في Excel.
- **روابط بحثية مساعدة**: يضيفها ويحذفها المشرف والإدارة، ويراها الجميع.
- **بنك المشاريع** (PDF وWord وExcel) و**دليل البحث** (PDF يُعرض داخل الصفحة ويُحمَّل) و**قالب البحث** (Word): يرفعها المشرف والإدارة، ويحمّلها كل مستخدم.
- رفع حتى 10 ملفات دفعة واحدة للبحث الواحد أو لبنك المشاريع.
- ملاحظة: تخزين KV المجاني 1 غيغابايت مشترك بين أبحاث الطلاب وملفات المكتبة.
